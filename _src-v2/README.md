# AK agencija site v2 (Astro source)

Source for alejkump.si `index.html`, `storitve.html`, `cene.html` and `assets/v2/*`.
GitHub Pages (Jekyll) ignores this underscore folder, so it is never served.

    npm install          # astro only, free
    npm run build        # -> dist/
    node copy-to-site.mjs   # copies the three pages + assets/v2 into the site root

Content is verbatim from the owner's brief; the design is written by hand
(no third-party HTML/CSS). Fonts are self-hosted under assets/v2/fonts (OFL).
